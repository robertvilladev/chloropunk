# Chloropunk — Music Plan

**Goal:** Two background loops plus a small mixer (master / music / sfx) on top of the [SFX work](2026-10-23-sfx.md). Spec: [audio addendum § Music](../specs/2026-10-23-audio-addendum.md#music-owner-approved-2026-10-23).

## Concepts

- **Buses.** A bus is a gain node many sounds flow through, so one slider scales them all. Graph: `music <audio> → musicGain ┐`, `sfx buffers → sfxGain ┘ → Phaser master (sound.volume, mute) → speakers`.
- **Decode vs stream.** Phaser's normal audio loader decodes a whole file into raw samples (5 min stereo 48 kHz ≈ 120 MB). Fine for SFX, too heavy for music. An `<audio>` element streams from disk and we route it into the same AudioContext.
- **Crossfade / duck.** Gain ramps (`linearRampToValueAtTime`) on per-track gain nodes. The curves and the "which track in which state" table are pure functions in `src/core/music.ts`, unit-tested.
- **Autoplay lock.** Browsers block sound until the first click/key. Phaser resumes its context then (`unlocked` event); the music player calls `play()` at that moment and fades in.

## Open questions for the owner

1. **Track → state.** Recommend NLV for Menu/Loadout, Spring for waves + level-up + shop (no duck between waves). Boss (M4) not built yet; decide then.
2. **Duck on overlays.** Recommend pause, game over and victory duck to ~30%.
3. **Credit placement.** Recommend a small bottom-right footer on MenuScene (`MUSIC: NLV · SPRING — CC-BY 4.0`) plus a `CREDITS` key/button that opens a short overlay with title, author, links, licence and changes.
4. **Encoding tool.** ffmpeg isn't installed. Recommend a one-off `pnpm dlx ffmpeg-static` (downloads ~80 MB to the pnpm store, not a project dependency). Alternative: `winget install ffmpeg`.
5. **Encoding settings.** NLV: trim to 0–4:34, 2 s fade-out, OGG Vorbis q4 (~4.5 MB). Spring: already a 160 kbps OGG; ship as-is (6.7 MB) unless its tail has silence too (ffmpeg `silencedetect` will tell), re-encoding lossy→lossy only if trimming is needed. Never commit the WAV.
6. **Safari.** Safari 18.4+ plays Ogg Vorbis; older Safari/iOS would get silence. Recommend OGG only; an M4A fallback is a later add (~10 MB more in the repo).
7. **Streaming vs decoding.** Recommend streaming (`<audio>` element). Cost: an `audio.loop` restart can have a tiny gap, hidden by the baked fade.
8. **Stacking.** Recommend building on PR #32's branch and retargeting to `main` once #32 merges.

The owner must listen to the loop restarts and mix levels; nobody can check those without ears.

**Owner decision (2026-10-23):** all 8 recommendations above accepted.
