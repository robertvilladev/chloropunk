# Veggie Vendetta — Milestone 3 (Look) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the game look like the approved mockups: pixel-art sprites (fighter, 5 enemies, pickups) in a 3/4 y-sorted arena with soft shadows and neon glow, the Chlorophyll theme and fonts on every screen, and the HUD, main menu, loadout, level-up and shop restyled. M3 is purely visual: no new gameplay, no SFX.

**Architecture:** Sprites are character grids stored as TS data (`src/art/`), turned into canvas textures at boot (3× baked, one texture per actor with named frames); game code only knows texture keys. Pure bits (grid validation, depth, facing, labels, font gate) live in tested modules; scenes only render. UI screens are built from one themed widget kit (`src/scenes/ui.ts`) so M4's summary/pause screens compose from the same parts.

**Tech Stack:** Phaser 3.90 (WebGL + Canvas), TypeScript strict, Vite 5, Vitest 4.

**Spec:** [`docs/superpowers/specs/2026-10-18-mvp-roguelike-design.md`](../specs/2026-10-18-mvp-roguelike-design.md) §6 (look and feel), §7 (screens). Approved mockups (copies): [`docs/superpowers/specs/mockups/`](../specs/mockups/README.md); hosted: design system https://claude.ai/artifact/9DHSn6f62spjQLXLqsCQee, screens https://claude.ai/artifact/273SegSV2CBPS1HX96Yr17. Earlier plans: [M1](2026-10-18-m1-waves-and-feel.md), [M2](2026-10-18-m2-build-crafting.md).

2. Art scope: fighter + 5 enemies each get a 2-frame walk and a hit frame; scrap/XP pickups get sprites; **weapons and items get no icons** (coloured tier frames only).

## Global Constraints

- Phaser 3.90 + TypeScript strict + Vite + Vitest; canvas **800×600** logical, `pixelArt: true`; keyboard WASD/arrows. CI (`npm run build`, `npm run test:coverage`) stays green.
- Sprites: **16×16 pixel grids drawn at 3×** (baked into the texture, so scaling is always an integer), fighter in a **pink hood with cyan visor**, flames/fuses `#ffd23f`. All game code refers to sprites **only by texture key**; facing is a **horizontal flip**. Grids are Claude-authored data, swappable later without code changes.
- Perspective: top-down 3/4, **y-sorted depth** (lower on screen draws in front), soft drop shadow under every actor, neon glow (WebGL FX) on projectiles, pickups and accents.
- Palette ("Chlorophyll") — only via `THEME`/`THEME_CSS`: ground `#12151b`, surfaces `#1c2029` / `#171a21`, line `#2c323d`, text `#edf2ec`, muted `#949ca3`. **Lime `#c6ff3d` = actions and good events** (primary buttons, scrap, crits, wave banner, positive deltas). **Pink `#ff4f9a` = state** (player, owned/selected, XP, offset shadows). Danger `#ff6b3d`. Rarity: grey `#a9b0b8`, cyan `#3ad8ff`, pink `#ff4f9a`, amber `#ffb13b`. No colour washes on the ground.
- Type: display **Bungee**, UI **IBM Plex Mono**, in-game numbers **VT323**.
- Motifs: radius 0; hard **4px pink offset shadow** under primary elements; tier chips on cards; **RGB-split on the logo and wave banner only**; a lime slime-drip edge on the main menu; barely-visible scanlines in menus only.
- Shop and level-up stay fully mouse- and keyboard-usable and keep stat previews on hover/focus. No key binding or scene flow changes.
- 60 fps with ~150 enemies + 6 weapons: no per-frame allocation in hot loops; no per-object post-FX on pooled sprites.
- Data-driven: new text content (weapon blurbs, character name) lives in `assets/data/`, not in scenes.
- Don't regress PR #13/M2: reset per-run fields in `create()`, `disableBody`/`enableBody` for pooled sprites, remove scene listeners on shutdown.
- Docs ride along (CLAUDE.md): update README/ARCHITECTURE/ASSETS_GUIDE/ROADMAP in the task that changes what they describe.

## Review Focus

1. **Fonts blocked or slow** — if Google Fonts is unreachable the game must still reach the menu within the timeout (fallback fonts), never hang on a never-resolving `document.fonts.load`; and a font that loads late must not leave the wave-1 banner in a fallback face. Task 1.
2. **Canvas renderer** — with `?renderer=canvas` the game boots and plays: no `postFX`/`preFX` call (undefined on Canvas), the low-HP vignette is a visible gradient (not a flat rectangle), sprites and shadows draw. Tasks 6, 7.
3. **Recycled pooled sprites** — a pooled enemy that dies mid hit-frame and respawns must come back on a walk frame, un-flipped/unflipped per its velocity, animating, with no stale tint. Task 4.
4. **Depth bands** — no actor, shadow, pickup or weapon can ever sort above effects/UI whatever its `y` (knockback overshoot, `y<0`, `y>600`, `NaN`); bursts, damage numbers and banners always draw above all actors. Task 5.
5. **Long or large text** — longest item/weapon name, a 4-digit scrap total and 6 owned weapons must not overflow shop/level-up cards or the HUD (wrap or truncate with `…`), and every key/mouse path (1–4, Shift+1–4, R, Tab/S/C, ←/→, Enter/Space, Esc) still works after the restyle. Tasks 2, 9, 10.
